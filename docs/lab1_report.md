# Отчёт по лабораторной работе №1

## Выполненный уровень

В рамках лабораторной работы выполнен уровень **«Базовый+»**.

Подготовлен каркас Python-проекта `research-global-health` с `src`-структурой и управлением зависимостями через `uv`. Настроены Ruff, mypy в строгом режиме, pytest, контроль покрытия кода и pre-commit.

Реализованы конфигурация приложения на `pydantic-settings`, настройка логирования и CLI на Typer с командами `version` и `check-config`. Для конфигурации и CLI добавлены автоматические тесты. Покрытие кода тестами превышает установленный минимальный порог 70%.

Добавлен файл `.env.example` с безопасными значениями настроек и подготовлена структура пакетов `models`, `sources`, `storage`, `pipelines` и `api` для следующих лабораторных работ.

Для проекта настроен GitHub Actions CI, выполняющий проверку Ruff, форматирования, mypy и pytest. CI успешно проходит на GitHub.

## Возникшие сложности

Основные сложности были связаны с первоначальной настройкой Python-инструментов и их совместной работой, поскольку ранее основной опыт разработки был связан с frontend-разработкой.

В процессе настройки были исправлены замечания Ruff к импортам и форматированию, настроена изоляция тестов от локальных переменных окружения и добавлена проверка минимального покрытия кода.

При настройке pre-commit некоторые файлы были автоматически исправлены хуками, после чего проверки были запущены повторно и успешно завершились.

## Принятые решения

Проект использует Python 3.12 и `uv` для управления окружением, зависимостями и lock-файлом.

Для mypy включён строгий режим проверки как исходного кода, так и тестов. Минимальный порог покрытия 70% зафиксирован в конфигурации pytest.

В pre-commit помимо Ruff, mypy и pytest добавлены базовые проверки YAML, окончания файлов, пробелов в конце строк и случайного добавления больших файлов.

В качестве источника данных для дальнейшего развития учебного проекта выбраны открытые данные WHO Global Health Estimates (GHE) о ведущих причинах потери лет здоровой жизни (DALYs). Конкретная аналитическая задача будет реализована в следующих этапах проекта.
